# 色彩

- 先定义中性色、一个主强调色、成功/警告/危险状态色和极少量效果色；用语义变量表达角色。
- 画面 70–90% 应由中性色承载。强调色只用于主要动作、当前状态和必要焦点，不把每个链接、图标和卡片都染成强调色。
- 普通文字对背景至少 4.5:1，大文字和非文字控件边界至少 3:1；焦点不能只靠颜色且需可见。
- 状态色必须与文字或图标共同表达含义。深色主题避免纯黑纯白振动，并确保边框仍能区分表面。
- 默认不使用装饰渐变、霓虹光晕或紫蓝“可信感”组合。只有确认的视觉方向或信息层级需要时才使用，并说明作用。
- 禁止在组件内散落大量十六进制值；对每个页面检查强调色占比与低对比次文字。
