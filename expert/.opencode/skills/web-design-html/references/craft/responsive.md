# 响应式

- 断点由内容何时拥挤决定，不照搬设备名单。至少检查 320、768、1280 px 宽度。
- 320 px 不得出现页面级水平滚动；长文本、表格、代码和媒体必须换行、裁切、滚动容器化或改为移动结构。
- 响应式是重排而不是同比缩小：多列改为单列，次要信息折叠或后置，操作保持可触达。
- 触控目标至少 44×44 CSS px 或具有等效间距；固定元素不得遮挡内容、焦点或系统安全区。
- 图片和视频使用响应式尺寸并保留比例；高密度媒体有合适 `srcset` 时仍必须是本地资源。
- 数据表在窄屏明确选择横向局部滚动、关键列固定或卡片化，不能让所有列挤成不可读文本。
- 用 `prefers-reduced-motion` 降低非必要动画，并检查横竖屏切换和 200% 缩放。
