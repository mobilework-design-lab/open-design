# 字体与排版

- 正文默认 15–18 px、行高 1.5–1.65，移动端不得低于可读尺寸；正文行宽控制在 45–75 个字符，通常 `max-width: 65ch`。
- 使用连贯的 1.2 或 1.25 字阶，整页不超过 6–8 个字号。标题越大行高越紧；32 px 以上可用轻微负字距。
- 最多两套字体、三个主要字重：阅读、强调、宣告。始终提供离线系统回退，不依赖远程字体。
- 全大写标签必须增加约 `0.06em–0.1em` 字距；小标签可轻微正字距。正文不两端对齐。
- 字体承担信息层级而非装饰。不要靠无意义超大字、极细小字或过多粗体制造“设计感”。
- 检查长标题、长单词、数字列、中英文混排和 200% 缩放；文字不得溢出、截断关键信息或与控件重叠。
