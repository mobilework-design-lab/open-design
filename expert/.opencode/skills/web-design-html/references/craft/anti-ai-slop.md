# 反通用生成痕迹复核

交付前逐项删除不能由产品语境解释的视觉习惯：

- 重复的玻璃拟态卡片、模糊背景和发光边缘。
- 任意紫蓝渐变、装饰光斑、波浪或与信息无关的背景图形。
- 所有容器、按钮、标签都使用胶囊或同一大圆角。
- 用 emoji 充当功能图标；改用本地 SVG、文本或原生控件。
- “大标题 + 三项统计 + 三张功能卡 + 通用 CTA”的可互换骨架。
- 虚构客户、评价、增长倍数、可用率和“Feature 1/2/3”填充文案。
- 为显得精致而增加无用途动画、漂浮装饰或滚动劫持。

目标是约 80% 成熟模式加 20% 产品特定选择。产品特定部分应来自用户任务：一个有理由的排版比例、符合领域的密度、一句准确微文案或一个高频工作流细节。若把品牌名替换后页面仍可无差别用于任何产品，说明方向仍然过于通用。

最后截屏式检查：首要动作是否唯一、卡片是否真的需要、强调色是否克制、圆角是否区分层级、内容是否诚实、焦点是否可见、320 px 是否溢出。任何未通过项都在 draft 中修复后再运行 finalizer。
