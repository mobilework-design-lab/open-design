# 设计系统解析

## 工作区优先

只有 `.web-design/design-system/DESIGN.md` 与同目录 `tokens.css` 同时存在、可读取且包含语义角色时，才把它们作为项目设计系统。若任一缺失、格式损坏或只含无语义色阶，则整体回退到本文件与 Skill 的 `assets/tokens.css`，不要混合出一套无法追踪的半覆盖主题。

## 语义令牌

至少为画布、表面、主文字、次文字、边框、强调、强调对比、成功、警告、危险、字体、字号、间距、圆角、内容宽度和焦点环定义语义变量。变量按用途命名，不按具体颜色或页面区块命名。组件值引用语义变量；少量一次性艺术细节可局部声明，但不得复制散落的品牌色。

## 使用方式

把实际使用的 token 声明复制到草稿 HTML 的 `<style>` 或草稿 CSS 中。最终站点不得引用 Skill 文件、`.web-design/design-system/` 或其他工作区内部文件。回退 tokens 只是中性起点，不是强制视觉主题；可以按已确认方向替换值，但必须保留角色、对比与状态含义。

设计方向有明确品牌约束时以用户约束为准；Craft 规则负责可读性和一致性，不得覆盖已确认的品牌事实。每个页面共享同一基础 token 集，页面特有差异用少量语义扩展表达。
